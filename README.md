# CareerPath

Aplikacja do organizowania procesu poszukiwania pracy — zarządzania zgłoszeniami, śledzenia ich statusów i planowania rozmów rekrutacyjnych.

## Funkcje

- Dodawanie, edytowanie i usuwanie zgłoszeń.
- Tryb gościa bez rejestracji — zgłoszenia zapisywane lokalnie w przeglądarce.
- Szczegóły zgłoszenia: link do oferty, lokalizacja, tryb pracy, widełki wynagrodzenia i notatki.
- Panel szczegółów otwierany po kliknięciu zgłoszenia.
- Wyszukiwanie, filtrowanie i sortowanie aplikacji.
- Dashboard ze statystykami, ostatnimi zgłoszeniami i nadchodzącymi rozmowami.
- Rejestracja, logowanie, odzyskiwanie hasła i ustawienia profilu.
- Panel powiadomień z przejściem do szczegółów zgłoszenia.
- Języki: polski, angielski i hiszpański.
- Motyw jasny, ciemny i systemowy.
- Responsywny interfejs oraz obsługa klawiaturą.

## Technologie

React · JavaScript · React Router · Tailwind CSS · Supabase · Lucide React · Vite · Vercel
